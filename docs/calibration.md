# Jev calibration worksheet

The current thresholds are starting values, not calibrated outcomes. With an authorized local key, run each seed at all three doses, with and without a kit. Do not commit real prompts or responses.

| Seed | Kit example | Expected association range |
| --- | --- | --- |
| doorbell | ESP32, thermal printer | literal signals → odd rituals |
| rain | none | weather → metaphor → unexpected systems |
| memory | notebook, microphone | abstract → physical interfaces |
| spoon | LEDs, servo | household → interactive object |
| forgotten password | none | technical → emotional connections |

For each expansion, hand-rate accepted nodes on **surprise** (0–3), **coherence** (0–3), **repetition** (0–3; lower is better), **buildable potential** (0–3), and **safety** (pass/fail). Record Jev's raw score and `noul`, acceptance count, latency and reported cost. Review disagreements before changing thresholds. Target 6–8 strong nodes when the candidates support it; never lower the safety cutoff just to hit a target count.
